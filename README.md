# KnowledgeHub AI

KnowledgeHub AI is an end-to-end Retrieval-Augmented Generation (RAG) platform that enables users to query one or more documents using Large Language Models.

The project evolves incrementally from a simple single-document RAG pipeline into a production-inspired AI knowledge platform supporting multi-document retrieval, vector databases, hybrid search, web interfaces, and intelligent document management.
